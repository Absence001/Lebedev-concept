# Экраны и информационная архитектура — mysun

Единый встраиваемый модуль = **один вертикальный скролл-нарратив** внутри рамки iPhone 17 (402×874), помещённый в квадратную секцию сайта. Задание закрывается связкой: **логотип → (скролл) → интерфейс → заказ**.

## JTBD

> «Соберу персональное солнце под себя и получу его домой как физический светящийся объект».

Услуга «доставка солнца» трактуется буквально: пользователь настраивает свет в стеклянной сфере и **заказывает доставку именно этой, своей сферы** как предмета.

## Карта (3 акта)

```
ACT 1  ИНТРО / МЕТАМОРФОЗА  (анимация — Codex, спек в prototype.md)
  S0 Знак        mysun по центру + тёплый bloom
  S1 Зажигание   bloom → живой орб; знак отдаёт свет
  S2 Стекло      орб → стеклянная линза, преломляет сцену; mysun уезжает в шапку MySUN
  S3 Сборка UI   вокруг сферы собираются табы / имя / слайдер / CTA
        ↓ (собран State01)
ACT 2  РЕДАКТОР  (State01 — собран, интерактив)
  Пресет (табы) + температура (слайдер) меняют свет в стекле в реальном времени.
  Имя редактируется (карандаш). CTA: «Заказать своё солнце».
        ↓
ACT 3  ФИНАЛ  (дизайн — Claude)
  Один эмоциональный экран «Теперь оно ваше»: живое солнце пользователя парит и дышит
  + тёплая фраза + «На главную». Продукт = сам светящийся объект (гиф/картинка).
  Коммерческий флоу (размер / адрес / проверка) намеренно вырезан — вне рамок тестового.
```

## Почему это проходит fail-критерии брифа

- **Метаморфоза функциональна:** знак не просто исчезает — его свет становится сферой, а буквы становятся шапкой и обвязкой UI (S1–S3). Не декор.
- **Понятно, что получаешь:** твоё персональное солнце — светящийся объект, к которому возвращаешься (эмоциональный финал).
- **Заказ логически вытекает из скролла:** собрал знак в сферу → настроил свет → «Заказать» → «Теперь оно ваше». Прямая цепочка без лишних шагов.

## Спецификации экранов

### State01 — Редактор (готов: `mysun/index.html`)
Перенос из Figma (node 8:1196) **1:1**. Отличие от макета — только объект «солнце»: пересоздан как живой свет в стеклянной линзе (свет сфокусирован снизу, Fresnel-кромка, каустика, top-left блик). Токены:
- Фон: `linear-gradient(204.7deg,#130b07,#26140d)` + звёздное поле + верхний тёплый glow.
- Стекло-пилюли: `bg rgba(255,255,255,.1)`, `border rgba(255,255,255,.1)`, `backdrop-blur 5px`, `radius 999/60px`.
- Типографика: заголовок/вордмарк — **Libertinus Serif** (встроен woff2); UI — SF Pro / system.
- Слайдер: тёплый трек (263px, `#fff→#fff600→#ff6200`) + ручка (8×25) + холодный трек (91px, `#0bf→#003cff→#fff`); подписи «Холодно / Тепло».

### Финал — «Теперь оно ваше» (`mysun/ready.html`)
Эмоциональный экран, не коммерция:
- Крупное живое солнце пользователя по центру: парит (float ~7s) + дышащий ореол; свет = настроенные пресет/температура.
- Эйрбоу «солнце доставлено» → serif-заголовок «Теперь оно ваше» → тёплая фраза.
- Единственная кнопка «На главную» (→ к началу). Опц. ghost «Сохранить солнце» — усиливает «храните его».
- Копирайт правится. Текущий вариант подписи: «Возвращайтесь к нему, когда станет пасмурно, — оно будет светить только для вас.»

## Статус

- State01 — готов (`mysun/index.html`).
- Финал «Теперь оно ваше» — собран (`mysun/ready.html`), в системе State01.
- Коммерческий флоу (размер/адрес/проверка) — вырезан по решению пользователя.
- ACT 1 (анимация) + сшивка/кликабельность editor→финал — Codex по `prototype.md`.

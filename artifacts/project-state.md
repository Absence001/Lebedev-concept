# Состояние проекта

## Проект

Тестовое задание в Студию Артемия Лебедева на позицию дизайнера.

## Текущее задание

Экран приложения для услуги «доставка солнца»: логотип по мере скролла превращается в элементы интерфейса и доводит до заказа. Прототип — self-contained веб-модуль для квадратной секции сайта.

## Зафиксированные решения

- Прототип — self-contained встраиваемый модуль. Вертикальный экран iPhone 17 **402 × 874** в квадратной секции сайта. Живёт в `mysun/`.
- `State01` (Figma node 8:1196) перенесён **1:1**. Визуальное направление драфта — источник правды.
- Логотип — текст-заглушка `mysun` / вордмарк `MySUN` живым текстом (Libertinus Serif встроен woff2). Финальный знак пользователь нарисует позже.
- Объект «солнце» пересоздан по референсам: **живой свет внутри редактируемой стеклянной сферы-линзы** (не оранжевый шар из Figma). Пресет = базовый характер, слайдер = температура.
- **Пресеты-звёзды = разные РИСУНКИ движения света** (не только цвет). **Слайдер = хронология нагрева → корректный blackbody-цвет** (формула в `prototype.md`).
- **Фон — чёрный** (`#000`) и на редакторе, и на финале. (Отменяет прежнее «тёплый градиент как в Figma».)
- **iOS-хром убран** (время/батарея/нижняя линия) — концепт как чистый веб-объект, не имитация айфона. (Отменяет прежнюю правку «статус-бар 1:1 из Figma».)
- Заголовок имени — не капсом, дефолт «My unic sun», редактируется карандашом.
- **ACT 3 = один эмоциональный финал** «Теперь оно ваше» (живое солнце + фраза + «На главную»). Коммерческий флоу (размер/адрес/проверка) **вырезан**.

## Лоадер переделан по референсу `loader.mp4` (сессия без Codex)

Механика референса разобрана покадрово (30 кадров / 3.93с): чёрный экран → серия ярких полноэкранных градиентных «арок», каждая ~130–150мс с перехлёстом (кроссфейд) → затухание в чёрный → надпись + кнопка. Воспроизведено:

- **Вспышки.** `.loader` + 6 слоёв `.flash` в `index.html`. Keyframes `loader-flash` (460мс, `opacity 0→.96→.92→0` + `scale 1.06→1`), стагер 150мс от 260мс; `filter: blur(26px)` на контейнере. Итог: каскад с перехлёстом, ровно как в референсе (проверено замером opacity по времени).
- **Гамма — наши звёзды.** Температурный проход: Бетельгейзе ~3500K (красно-оранжевый) → Арктур ~4300K (янтарь) → Капелла ~5000K (золото) → Солнце ~5800K (тёпло-белая, самая яркая) → Ригель ~12100K (сине-белая) → затухание в ночную синь. Соседние вспышки близки по тону, поэтому наложения смешиваются чисто (первая версия давала лиловую муть — переделано).
- **Финал лоадера.** «SUN DOSTAVKA» (тот же вордмарк, что в шапке) стоит **внизу** экрана + аккуратная стрелка вниз под ней. Интро-позиция лого переехала из центра в низ: `INTRO_BOTTOM_GAP = 148`, `INTRO_SCALE = 1.5` (было `scale 2.05` по центру), отсчёт от `scene.getBoundingClientRect()`. Стрелка — SVG-глиф на всю площадь вьюбокса (24px), `inset-block-end: 80px`, мягкий `hint-bob` как приглашение к скроллу.
- **Скролл «тугой» + баунс.** `--scroll-length` 3496px → **5000px**. Ревил интерфейса переведён с `setMotionState` на `setBounceState` (`easeOutBack`, c=2, distance 24px, scale 0.945→1, blur 4→0): перелёт 13.2% (~3px за цель) — заметно, но не карикатурно. Порядок сохранён: шапка → табы → заголовок → слайдер → **кнопка последней**.
- **По скиллу `make-interfaces-feel-better`.** Одноразовые staged-входы — на `@keyframes` (`loader-word` / `loader-word-bounce` / `loader-hint`, стагер 140мс), интерактивные состояния остались на прерываемых `transition`. Только `opacity` / `blur` / `scale`, `will-change` точечно, `prefers-reduced-motion` уважается (лоадер отключается, трек 874px).
- **Починено по ходу:** (1) шорткат `animation` в правиле с большей специфичностью **обнулял** `animation-delay` — все 6 вспышек шли одновременно (кадр выглядел мутной смесью); делеи перенесены в селекторы той же специфичности; (2) вход надписи/стрелки был на `transition` и залипал в состоянии `is-loading` — переведён на keyframes; (3) контролы «мигали» на первом кадре из-за 150мс transition на opacity до того, как скролл-прогресс выставит 0 — во время `is-loading` им задан `transition: none`; (4) в `setBounceState` при полном проявлении inline-стили снимаются, иначе они перебивали CSS `:active { scale(.96) }` (баг был и в прежнем `setMotionState`).
- **QA-харнесс (вне проекта).** В `scratchpad/serve.js` добавлен `?freeze=<ms>`: глушит таймер лоадера и ставит `currentTime` всем анимациям — позволяет снимать честные кадры лоадера в headless Chrome. В файлы проекта не попадает.

## Триггер сцены: клик вместо скролла + иконки Gravity UI

- **Скролл убран как драйвер.** `.frame{overflow:hidden}`, `--scroll-length` → 874px, слушатель `scroll` снят, `getScrollProgress()` теперь возвращает `timelineProgress`. Сцена проигрывается как **таймлайн** (`REVEAL_MS = 3400`, `easeInOutCubic`, rAF) по клику: на стрелку **или на любое пустое место экрана** (обработчик на `.scene` игнорирует `button/input/a/canvas/.settings-panel`, повторный запуск заблокирован флагами `revealPlaying/revealDone`). `setProgress()` переведён на ту же шкалу — `?p=` для QA работает.
- **Порядок:** клик → градиентные вспышки (класс `is-transition` реиграет те же `loader-flash`) → под их затухание интерфейс **выезжает снизу вверх**. Окна ревила смещены в 0.62…1.0, дистанция вылета 24 → **56px**, баунс (`easeOutBack`) + opacity + blur сохранены; кнопка приходит последней.
- **Градиенты плавнее.** Было 460мс / шаг 150мс с резкой кривой — «дёргало». Стало **1100мс / шаг 220мс**, кривая `cubic-bezier(.45,0,.55,1)`, мягкие полки (32% .88 → 64% .8), scale 1.12→1, blur контейнера 26 → 34px. Лоадер на открытии — `LOADER_MS = 2450`.
- **Вордмарк — точный вектор из Figma.** Живой текст (Libertinus) читался «как картинка», буквы не совпадали с макетом. Экспортирован вектор `48:595` из сплэша 41:252 → `assets/logo-wordmark.svg` (216.808 × 32.446, fill white). В шапке 150px, в интро ×1.5 = 225px (совпадает с пропорцией сплэша: 54% ширины экрана). Разметка: `.wordmark > .wordmark-text > img.wordmark-vector` — анимации и `measureMorph()` работают как раньше.
- **Иконки — Gravity UI** (`@gravity-ui/icons`, инлайн `currentColor`): `arrow-left` (назад), `gear` (настройки), `pencil` в белом круге (правка имени), `arrow-down` (подсказка скролла). Старые `<img>`-иконки из Figma убраны, правило `.gbtn svg{display:none}` перекрыто для `.gicon`.
- **Стрелка — в контурном круге.** Кольцо 44px, `border 1px rgba(255,255,255,.28)`, фон прозрачный, глиф уменьшен до 16px. Кольцо повешено на `.hint-inner`, а не на кнопку: на кнопке оно **просвечивало сквозь градиенты** во время вспышек.

## Пресеты звёзд (реализованы полностью — motion + цвет)

Прежняя запись: «Пресеты = разные рисунки движения света; слайдер = температура/цвет». Теперь реализовано полностью и объединено: **каждый пресет = температура (цвет по blackbody) + свой набор параметров орба** (рисунок движения света, размер, светимость), примерно под реальные звёзды. `STAR_PRESETS` в `motion.js`, применяется в `selectPreset` через `window.mysunOrb.setParam` + `applyTemperature`:

| Звезда | Тип, ~T | Характер (параметры) |
|---|---|---|
| Солнце | G2V 5800K | базовая живая грануляция, spin 1.4, radius .34, warp .31 |
| Арктур | K1.5III 4300K | оранжевый гигант: медленный, мягкий, крупнее (spin .85, radius .42, haze .26) |
| Капелла | G-гиганты 5000K | яркая, активная, жёлто-белая (exp 1.72, coreWhite .16) |
| Бетельгейзе | M2Iab 3500K | красный сверхгигант: огромный, бурная медленная конвекция (radius .5, spin .5, warp .62) |
| Ригель | B8Ia 12000K | голубой сверхгигант: горячий, энергичный, гладкий, яркий (spin 2.1, exp 1.95, bloom .78, warp .22) |

Состояние переносится на финал (через `getState()`→`sessionStorage`), т.е. финальный орб = звезда игрока.

- **Побочный эффект:** подзаголовок «Холодное и ясное» статичный — не меняется под звезду (копирайт, кандидат на доработку).
- **Не синхронизировано:** слайдеры в панели настроек (`settings.js`) не отражают параметры пресета (панель слушает только смену цвета). Не критично; кандидат на доработку.

## Слайдер кельвинов заменён на «Нагрев» (IA-решение)

**Проблема.** После того как пресеты стали «настоящими звёздами» (своя гамма + температура), слайдер кельвинов стал вредным: (1) он перетирал выбор пользователя — Бетельгейзе после сдвига становилась голубой и переставала быть собой; (2) «3000 K / 15000 K» — жаргон, метки не на языке пользователя; (3) он настраивал **рендер**, а по ТЗ метаморфоза обязана собирать **заказ** → прямое попадание в fail-критерий брифа «Пользователь не понимает, что именно заказывает».

**Решение (выбор пользователя).** Один слайдер = **нагрев звезды**, ведёт сразу три вещи:
- **размер** — диаметр объекта, показывается числом («30 см») по центру под шкалой;
- **светимость** — exposure / glow / bloom / rimGain;
- **активность магмы** — flowSpeed / warp / contrast / lift.

У **каждой** звезды свой диапазон `energy: { calm → blaze }` в `STAR_PRESETS`, поэтому нагрев не ломает идентичность: Бетельгейзе греется медленно и бурно (flow 0.12→0.75, warp 0.5→1.25), Ригель — стремительно (flow 0.6→2.8). Цвет задаётся **только** пресетом; `applyTemperature` больше не вызывается слайдером.

Сопутствующее:
- подписи шкалы: «Тлеет» — **N см** — «Пылает» (диаметр ярче краевых подписей, tabular-nums);
- дорожка шкалы больше не blackbody-градиент, а «тускло → ярко» **в цвете выбранной звезды**;
- подзаголовок стал живым: «Тихое и тёплое» → «Ровное и ясное» → «Яркое и живое» → «Раскалённое и бурное» (ровно 3 слова, структура спанов сохранена — иначе ломается пословное появление в ACT 1);
- лучи фона ярче на разогретой звезде;
- нагрев и диаметр уходят в заказ и в `sessionStorage` → финал воспроизводит именно ту звезду.

Проверено: 5/5 пресетов сохраняют цвет при любом нагреве, диапазоны у всех разные, 12→48 см, 0 ошибок в консоли, финал получает верные параметры.

## Текстовая анимация: скилл `serega-emotional`

Установлен из `github.com/mishanaer/deslop/tree/main/serega` (обе вариации: emotional + gentle, они ссылаются друг на друга) в `~/.claude/skills/` и `ai-rules/skills/`. Библиотека WAAPI скопирована в проект **как есть** — `mysun/vendor/serega-emotional.{js,css}` (правило скилла: «Treat a requested animation library as binding»). Подключается ES-модулем, кладёт `window.seregaEmotional`.

**Где применено:**
- подпись состояния под именем солнца («Яркое и живое» и т.д.);
- заголовок финала «Теперь оно ваше».

**Сценарий подписи:** появляется посимвольно, когда собран экран редактора; **уходит, пока крутим ползунок**; на отпускании возвращается с фразой, соответствующей выбранному радиусу. Уход — сознательное отклонение: скилл вход-only («Exit: none. Do not invent an exit animation unless the user requests one»), пользователь запросил явно. Уход сделан мягче и короче входа (150 мс, opacity+translateY+blur), как требует `make-interfaces-feel-better`.

Контракт скилла проверен на живой странице: первая задержка 25 мс, стаггер ровно 25 мс, длительность 680 мс, easing linear, `aria-label` с полной фразой сохраняется.

**Логотип:** иконка-солнце убрана из шапки, остался только вордмарк «SUN DOSTAVKA» (удалены `.wordmark-mark*` из HTML/CSS/JS вместе с логикой подгонки пропорций).

### Пилюля радиуса — видна только во время взаимодействия
Появление: opacity + blur + scale с отскоком (`cubic-bezier(.34,1.56,.64,1)`, 340 мс). Уход — без отскока, 150 мс. *Отклонение от скилла:* он требует `bounce: 0`; отскок добавлен по прямой просьбе, поэтому только на входе.

**Два исправленных бага (оба нашлись только на живой мыши, синтетические события их маскировали):**
1. **Пилюля залипала после отпускания.** Клик мышью фокусирует нативный `input[type=range]`, а признак активности читался из `document.activeElement`. `:focus-visible` тоже не подошёл — это браузерная эвристика, в автоматизации даёт другой результат. Решено детерминированно: модальность отслеживается своим флагом (`sliderPointerId` + `sliderKeyboardActive`), клавиатурная серия гасится по таймауту 900 мс и по blur.
2. **Подпись залипала скрытой.** Скрытие висело на `p < 0.99`, а редактор становится активным при `p > 0.94` — в этом зазоре экран рабочий, а подпись пропала навсегда. Переключение переведено на единый порог `editorReady` и срабатывает только на переходе состояния.

## UI слайдера по рефу `artifacts/slider.mp4` + слой интерактива

**Слайдер.** Вместо сплошного трека — линейка из штрихов от края до края (`repeating-linear-gradient`, шаг 9px). Пройденная часть красится акцентом звезды и разгорается к риске (mask-градиент), оставшаяся — белая на 22%. Риска — тонкая вертикальная линия 3×28 со свечением. Значение диаметра — **пилюля над риской**, едет за ней и клампится по краям линейки (ширина берётся из `getBoundingClientRect`, не `offsetWidth`, иначе выезжала на 0.3px). Подписи «Тлеет / Пылает» вынесены **под** линейку, без плашек — по эскизу пользователя (концевые плашки рефа 4:31/3:00 намеренно не делались).

**Акцент.** Введена `--accent-rgb` = `ramp.c2` выбранной звезды. Раньше линейка красилась в `--bb-rgb` (blackbody-тонировка), а у Солнца она почти белая — пройденные штрихи сливались с обычными. Теперь у каждой звезды свой акцент: Солнце `255 140 26`, Арктур `255 128 31`, Капелла `255 194 61`, Бетельгейзе `245 85 31`, Ригель `91 160 255`.

**Тактильность:** при перетаскивании риска вырастает 28→32px, пилюля приподнимается и растёт на 6%.

**Слой интерактива (skill `make-interfaces-feel-better`).** Для табов, круглых кнопок шапки, CTA, имени и кнопок настроек: явные `transition-property` (никаких `all`), 150ms `cubic-bezier(.2,0,0,1)`, прерываемые переходы. Наведение — только лёгкий сдвиг фона/цвета (частая интеракция). Нажатие — `scale(.96)` + `opacity` + микро-`blur`. Убраны старые `scale(.94)` и `scale(.98)` (`.94` нарушает правило «не ниже .95»). Хит-эрия слайдера поднята до 44px. Добавлен `prefers-reduced-motion` — трансформ и блюр снимаются, статичные признаки состояния остаются.

## Шейдер орба переписан заново (референс `artifacts/bubble motion graphic.mp4`)

Прежний объёмный gyroid-raymarching **удалён целиком**. Первая попытка (плёночная интерференция) дала баг: `pathDifference = thickness / cos` взрывался у края → сверхчастотные полосы → после bloom «иглы». Отброшена.

Действующий шейдер — **liquid glass**, всё низкочастотное by construction (нет деления у края, нет бэндинга):
- domain-warped fbm (3 октавы) внутри сферы → плавные перетекающие поля света;
- 5-ступенчатая цветовая рампа `c0..c4` + `rim` — это и есть «своя гамма звезды»;
- стеклянная оболочка: затемнение под поверхностью + тонкий яркий кант `pow(edgeRatio, rimWidth)`;
- тёплый зеркальный блик сверху-слева, внешний ореол, bloom;
- `bounds`-затухание к краю канваса (иначе обрезанный ореол давал видимый квадрат — было, исправлено).

**Пресеты** (`STAR_PRESETS` в motion.js): у каждой звезды своя рампа + характер. Солнце (золотое), Арктур (медный гигант, медленный), Капелла (золотисто-кремовая, энергичная), Бетельгейзе (красный сверхгигант, крупный, warp 0.8, самый медленный), Ригель (бело-голубой, самый быстрый и яркий). Гамма — солнечная, кроме Ригеля (он по физике горячий бело-голубой).

**Панель настроек** пересобрана под новый шейдер: 22 контрола = ровно 22 параметра состояния, мёртвых ползунков нет. Группы: Форма / Поток света / Стекло / Свечение / Общее.

**Температурная шкала:** насыщенный градиент (физический порядок и позиции сохранены), тонирует рампу поверх пресета — работает на всех пресетах. Тусклый UI-текст поднят с `.2` до `.55–.62`.

### Проверено (перед показом)
Шейдер компилируется, `orb-fallback` не срабатывает; 0 ошибок в консоли на обоих экранах; 21/21 ползунок реально меняет состояние шейдера; 5/5 пресетов дают разные рампы и параметры; шкала меняет температуру и цвет на каждом пресете (3400K ↔ 13300K); ручка слайдера перекрашивается; финал восстанавливает звезду 1:1 через sessionStorage (рампа + радиус + лучи).

**Исправленные по ходу баги:** видимый квадрат канваса вокруг орба; серый блик снизу (неверный знак Y); провал поля в почти-чёрный `c0`; `setPointerCapture` до применения температуры обрывал обработчик слайдера (обёрнут в try/catch, как в свитчере).

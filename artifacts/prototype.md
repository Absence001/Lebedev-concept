## Что делать

Превратить `mysun/index.html` из статичного State01 в **scroll-driven метаморфозу**: старт — только логотип `mysun`; по мере скролла логотип рождает сферу и раскладывается в интерфейс; в конце — полностью собранный State01. Единый модуль, встраиваемый в квадратную секцию сайта (iframe). Скролл-контейнер = внутренняя область телефона (pin/scrub), внешняя страница не обязана скроллиться.

## Техн要ика

- Стек: self-contained. Рекомендуется `motion` (Framer Motion) для React-версии **или** GSAP ScrollTrigger для ванильной. `package.json` в `prototype/` уже есть, но проще собрать отдельный лёгкий модуль — согласовать с Claude, если трогаешь vinext.
- Драйвер — **прогресс скролла p ∈ [0..1]** по ~3–4 высотам экрана; всё привязать к p (scrub), не к таймауту.
- `transform`/`opacity`/`filter` only (GPU). `will-change` точечно. Обязателен `prefers-reduced-motion: reduce` → сразу показать State01 без переходов.
- Не ломать конечный кадр: при p=1 DOM/стиль обязаны совпасть с текущим `mysun/index.html` (пиксель-в-пиксель).

## Раскадровка (маппинг p → элементы)

Easing по умолчанию: вход `cubic-bezier(0.2,0,0,1)`; для «оседания» элементов — spring `{duration:0.3–0.6, bounce:0}` (bounce всегда 0). Заголовок дробить на слова, стагер ~80мс; блоки — стагер ~100мс (см. `make-interfaces-feel-better/animations.md`).

| p | Стадия | Что происходит |
|---|---|---|
| 0.00–0.15 | **S0 Знак** | Сцена (фон-градиент + звёзды) видна. По центру serif-`mysun` (Libertinus). За словом — тёплый радиальный **bloom** дышит (7s). Подсказка скролла ↓. |
| 0.15–0.45 | **S1 Зажигание** | Bloom стягивается к точке внутри знака и разгорается в **живой орб** (свет из `sun.mp4`): масштаб 0.1→0.7, яркость/plasma растут. Буквы `mysun` начинают расходиться (tracking + расхождение по X), точка/counter отдаёт свет орбу. |
| 0.45–0.75 | **S2 Стекло** | Вокруг света нарастает **стеклянная оболочка**: появляются `.rimlight`, `.sun-glass` (Fresnel, блик, каустика) — оболочка «застывает» (можно через blur→0 + inset-shadow opacity 0→1). Лёгкое **преломление фона** сквозь линзу (масштабированная/смещённая копия фона под маской круга, как в `animation.mp4`; амплитуда искажения растёт 3.7→14.4 — из Figma-shader). Слово `mysun` поднимается вверх и **ужимается в шапку** `MySUN` (позиция → top bar center, size 48→21px). |
| 0.75–1.00 | **S3 Сборка UI** | Сфера садится в центр (масштаб →1, финальные координаты State01). Вокруг **стагером** въезжают элементы (`opacity/ y:12→0 / blur:4→0`): (1) кнопки back+gear, (2) табы-пресеты, (3) заголовок «MY UNIC SUN» + подпись, (4) слайдер, (5) CTA «Заказать своё солнце». При p=1 — ровно State01. |

Микродетали (make-interfaces-feel-better):
- Все интерактивные состояния (после p=1) — CSS transitions (прерываемые), не keyframes.
- CTA/кнопки: `active: scale(0.96)`.
- Сфера сохраняет «дыхание» (halo breathe + plasma drift) и после сборки — это свойство объекта.
- Переход к ACT 2/заказу — вне этой задачи (см. screens.md), но оставь хук `onComplete(p=1)`.

## Пресеты (звёзды) = разные РИСУНКИ анимации (обязательно)

Табы Солнце / Арктур / Капелла / Бетельгейзе / Ригель — это **не просто разные цвета, а разные паттерны движения света** внутри сферы (свой «рисунок» плазмы/конвекции). Переключение таба меняет и рисунок, и базовую температуру (позицию слайдера). Ориентир (характер сверяй по звезде, детали — на твоё усмотрение):

| Пресет | База K | Цвет | Рисунок света внутри сферы |
|---|---|---|---|
| Солнце | ~5800 | тёпло-белый | ровное спокойное свечение, мягкая гранулация |
| Арктур | ~4300 | оранжевый | крупные медленные конвективные пятна (старый гигант) |
| Капелла | ~5000 | золотой | двойное ядро, мягкое биение двух центров |
| Бетельгейзе | ~3500 | красный | крупная нестабильная турбулентность, редкие вспышки (красный сверхгигант) |
| Ригель | ~12100 | сине-белый | плотный высокочастотный шиммер, острые блики (горячая) |

Рисунок = разная скорость / масштаб / частота дрейфа плазмы + разная текстура (можно noise/turbulence-шейдер, как Figma-shader amplitude 3.7→14.4). Смена пресета — плавный кросс-фейд рисунка, не резкий.

## Слайдер = хронология звезды → КОРРЕКТНЫЙ цвет (blackbody)

Слайдер отражает нагрев звезды во времени: звезда рождается холодной-красной и, нагреваясь за миллионы лет, синеет. Позиция → температура T ∈ [3000..15000] K → **цвет по blackbody**, физически корректный (низкие K — красно-оранжевый, ~6500K — белый, высокие — сине-белый). Свет внутри сферы обязан принимать этот цвет. Метки: «Холодно» (лево ≈3000K, оранжевый) → «Тепло» (право ≈15000K, синий).

Формула (аппроксимация Tanner Helland, t = T/100), затем clamp 0..255:
```
R = t<=66 ? 255 : 329.698727446 * pow(t-60, -0.1332047592)
G = t<=66 ? 99.4708025861*ln(t)-161.1195681661 : 288.1221695283*pow(t-60,-0.0755148492)
B = t>=66 ? 255 : (t<=19 ? 0 : 138.5177312231*ln(t-10)-305.0447927307)
```
Полученный RGB — базовый цвет света. Сохрани структуру сферы из `mysun/index.html` (свет сфокусирован снизу, каустика, Fresnel-кромка, блик), но тонируй градиент этим цветом. Пресет выставляет стартовую T (позицию ручки), слайдер её меняет.

## Кликабельность (весь прототип)

Прототип должен быть **полностью кликабельным**, не только ACT 1:
- Табы-пресеты переключают рисунок + базовую T (активный = белый).
- Слайдер тянется (draggable ручка + tap по треку), меняет цвет света в реальном времени по blackbody.
- Имя «MY UNIC SUN» — карандаш открывает inline-редактирование.
- CTA «Заказать своё солнце» → короткий лоадер → финальный эмоциональный экран «Теперь оно ваше» (`mysun/ready.html`: солнце парит + фраза + «На главную»). Коммерческого флоу нет.
- «На главную» → возврат к началу (лого/State01).
- Финальный экран приходит готовой вёрсткой/CSS (система State01) — твоя часть: переход editor→финал (мягкий кросс-фейд, вход блоков stagger ~100мс) и обратно.

## Текстовые анимации — skill `pixel-point/animate-text`

Для анимации ТЕКСТА используй community-skill `animate-text` (Pixel Point): `npx skills add pixel-point/animate-text --skill animate-text`. Работает с Motion / GSAP / WAAPI / Remotion. Приоритетный эффект по вкусу заказчика — **motion-blur** (`soft-blur-in` и родственные): текст въезжает с размытием в движении.

Где применять:
- Заголовок «MY UNIC SUN» + подпись при сборке State01 (стадия S3) — вход по словам, motion-blur + stagger.
- Вордмарк `mysun` → `MySUN` в метаморфозе.
- Метки табов и лейблы (тонко).
- Финал `ready.html`: эйрбоу → заголовок «Теперь оно ваше» → фраза — последовательный вход с motion-blur.

Совмещай с `make-interfaces-feel-better` (stagger слов ~80мс, блоков ~100мс, spring bounce=0). Motion-blur — точечно, на входах, не на каждом элементе.

## Definition of Done

1. Скролл 0→1 воспроизводит S0→S3 плавно, обратимо (скролл вверх — реверс), scrub-привязка.
2. При p=1 — пиксель-в-пиксель State01 (`mysun/index.html`).
3. Логотип **буквально** становится сферой (свет) + шапкой (слово) — не просто исчезает.
4. 60fps на среднем ноутбуке; `prefers-reduced-motion` уважается.
5. Модуль встраивается в квадратную секцию сайта (iframe-friendly, без внешних зависимостей рантайма / шрифты встроены).
6. Каждый пресет-звезда даёт визуально различимый рисунок света (не только цвет).
7. Слайдер меняет цвет света строго по blackbody для своей T; пресет задаёт стартовую T.
8. Прототип кликабелен от логотипа до экрана «Солнце в пути»; все переходы плавные и обратимые.

Вопросы по конечному состоянию или токенам — сверяться с `mysun/index.html` и спросить Claude (владелец дизайна/ИА).
